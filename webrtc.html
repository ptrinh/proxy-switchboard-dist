WebRTC & IP leaks

Proxy Switchboard

🌐 English · Tiếng Việt

Even with the proxy on, a browser feature called WebRTC can still reveal your real IP address. Here's how to stop it.

📱 Phone (Android / iOS)

You're already protected — the app runs as a VPN and covers everything. Just keep the proxy connected. Nothing else to do.

💻 Computer (Mac / Windows / Linux)

Turn on TUN mode in the app (Settings → Advanced, or the menu). It protects every app automatically. You'll be asked for your password the first time.

Don't want TUN mode? Fix it in your browser instead:

  • Chrome / Edge / Brave — install WebRTC Network Limiter and set it to use your proxy.
  • Firefox — open about:config, set media.peerconnection.enabled to false.
  • Safari — use TUN mode above.

✅ Check it worked

With the proxy on, open browserleaks.com/webrtc. The IP it shows should be your proxy's — not your real one.

Note: some proxies can't carry video-call traffic, so WebRTC may simply stop working when protected. That's fine — it means your IP isn't leaking.
