Roadmap

Proxy Switchboard · a best-effort view of where the project is headed

Proxy Switchboard routes traffic per destination: each app, host, or network can take a different proxy — or go direct. This page is not a commitment on dates or ordering; priorities shift with real-world feedback. The guiding principle is to make per-destination routing just work on every device, especially TVs. Priorities, in order: reliability, then platform parity, then new features.

Have a request or found a bug? Get in touch — user feedback drives this list.

Recently shipped

  • App picker in the rule editor (Android) — pick an app from a searchable list instead of typing its package name.
  • Private DNS compatibility — hostname rules keep working when the device's Private DNS is set to "Automatic".
  • CIDR routing rules — route an IP range (e.g. 10.0.0.0/24, IPv4 or IPv6) to a proxy, now surfaced in the rule editor.
  • Faster proxied connections — a large jump in single-stream speed through a WireGuard proxy, and warm connections that make streams start quickly.
  • Streaming stability on Android TV.

In progress

  • Better UDP handling through proxies — when a proxy can't carry UDP, fall back cleanly instead of letting apps stall.
  • In-app diagnostics — a "Test route" that reports a concrete reason when a route fails, instead of a silent timeout.
  • Ship parity — bring the latest engine fixes to iOS, tvOS, and macOS.

Planned

  • Per-app rules on Android and TV — "this app → that proxy" from the UI, not just the global split tunnel.
  • Config import / export — QR import on Android/TV and on the desktop.
  • Proxy subscription URLs — add proxies from ss:// links and subscription lists on desktop (already on mobile).
  • On-demand / auto-connect — connect automatically on chosen Wi-Fi networks, and restart on boot for always-on TV setups.

Later

  • One-button WireGuard to your own server — self-hosted, fast transport plus per-destination routing.
  • Shareable rule sets — import and subscribe to community rule lists.
  • Fuller Windows / Linux desktop app.
