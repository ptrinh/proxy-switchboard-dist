# Proxy Switchboard — Distribution

Public release channel for **Proxy Switchboard**. The application source is
private; this repo only hosts the Sparkle auto-update feed and signed,
notarized build artifacts.

- **Feed:** `https://raw.githubusercontent.com/ptrinh/proxy-switchboard-dist/main/appcast.xml`
- **Downloads:** GitHub Releases (attached `.zip` per version)

Releases are published from the private source repo via `ui/release.sh`.
